📖 Guide d'usage

🔎 Filtres + recherche (ci-dessus)

Tout : les 30 articles. ★ Fiches : 29 articles avec produits/timeline/actions extraits des pages détail. ⏰ Consultations : 6 appels à feedback UE avec deadlines (dont 2 ouvertes : 10 et 16 sept 2026). 📅 Calendrier : 16 échéances d'entrée en vigueur triées. La recherche fouille titre FR + résumé + produits + timeline + actions.

🖥️ Dashboard dynamique

En local avec l'API : pip install requests beautifulsoup4 puis python api.py → http://localhost:8080. Bouton FR/EN, recherche live, boutons +Fiche détaillée, vues Consultations / Fresh / Calendar, endpoints /api/articles?search=…, /api/consultations, /api/fresh?days=30, /api/calendar, /rss.

🔔 Veille RSS

Flux des 20 derniers articles : data/rss.xml (statique, régénéré à chaque scrape) ou /rss (API). À ajouter dans Thunderbird, FreshRSS ou tout lecteur RSS.

⚙️ Fonctionnement

agrinfo.eu → scraper.py (BeautifulSoup) → SQLite data/agrinfo.db + JSON data/articles/*.json → api.py / index.html. Différences vs site officiel :

  • Fiches détaillées : chaque page /book-of-reports/… est ouverte et découpée en Produits impactés, Ce qui change, Timeline, Actions recommandées, lien EUR-Lex (29/30 articles).
  • Traduction FR : titres + résumés via MyMemory (gratuit, cache en DB, badge FR auto). Le site officiel est en anglais.
  • Consultations : détection Have Your Say + extraction des deadlines (regex until / by / closed on + date).
  • Calendrier : dates normalisées depuis les Timelines (dates exactes + trimestres Q4 2026 → 2026-10-01).
  • Recherche : 7 champs (titre, résumé, règlement, produits, changements, timeline, actions) — le site officiel oblige à ouvrir chaque fiche.

🔄 Mise à jour

Automatique via GitHub Actions (.github/workflows/update.yml) : cron quotidien 0 6 * * * (06:00 UTC) + déclenchement manuel (Actions → Run workflow). Le job installe requests + beautifulsoup4, lance python scraper.py (fiches + trad FR + rss.xml + export.json), puis commit/push si changements. Publication statique via GitHub Pages (branch master, dossier /) : le dashboard utilise data/export.json en repli quand l'API est absente.

python scraper.py     # scrape + détails + FR + rss.xml + export.json
python api.py         # dashboard local http://localhost:8080
git add -A && git commit -m "update" && git push origin master

Limites : quota MyMemory 5000 car/jour sans clé (dégradation propre en EN), sélecteurs HTML à ajuster si agrinfo.eu change de design.
